# 山本香料株式会社 トップページ デザインデモ

コーポレートサイト リニューアル案（トップページ）の、動きつきデザインデモです。顧客確認用のプレビューで、本番のコードではありません。

- 公開先: https://nishioka-tsubasa.github.io/yamamoto-perfumery-top-demo/
- 検索エンジンには載らない設定（noindex）にしています。
- 画面幅768px以上はPC版（1440px基準）、それ未満はスマホ版（390px基準）を、画面幅に合わせて拡大・縮小して表示します。

## 動き（香りの演出）

| 番号 | 名前 | 内容 |
| --- | --- | --- |
| 01 | 香りの軌跡 | 最初の画面の書から「お問い合わせ」の書まで続く細い線が、スクロールに合わせて霞が晴れるように上から現れる |
| 02 | 香りの霞 | 背景のやわらかい色がゆっくり漂う（柑橘 → ラベンダー → 緑） |
| 03 | 香り立ち | 写真が、ぼんやりした状態からピントが合って現れる |
| 04 | 香りの粒 | 線のそばを、ぼかした淡い光の粒が少しだけ上へ漂う |
| 05 | 見出し | 一文字ずつ、霞が晴れるように現れる |
| 06 | ノート表示 | 画面左端の「TOP / MIDDLE / LAST」がスクロール位置に合わせて移る |

スマホでは 01 と 02 だけを動かします。OSの「視差効果を減らす／動きを減らす」設定が有効な場合は、すべて静止で表示します。

## ファイル

- `index.html` … ページ本体
- `demo.css` … 画面の枠と動きの定義
- `demo.js` … 動きの制御
- `assets/` … 写真・ロゴ・書。すべて山本香料株式会社の現行公式サイト（www.ypcyy.co.jp）に掲載されている素材
